# 雾紫 · Violet Mist

Ankiki 的视觉风格。一句话概括：

> **干净的浅灰底，角落里透出一层淡淡的紫粉色雾气；内容放在白色卡片上，最重要的一块用紫粉渐变点亮。**

它想给人的感觉是「安静、专注，但不冷」：大部分界面是克制的中性色，颜色只出现在两类地方，一是品牌紫（告诉你「这里可以点」），二是语义色（告诉你「这张卡是什么状态」）。

下面的经验可以直接搬到其他 App。所有数值都来自 `src/styles.css`（桌面）和 `src/mobile.css`（手机）。

---

## 1. 五条核心原则

1. **底色不是纯白，是带一点蓝紫的灰**。`#f5f6fb` 比纯白柔和，让白色卡片自然地「浮」起来，不需要很重的边框。
2. **雾气只放在角落**。两团极淡的径向渐变（紫在右上、粉在左下，透明度只有 6%～8%），没注意时看不出来，去掉后整个界面会立刻变「冷」。
3. **一屏只有一块渐变**。首页的「今日待学」卡片用紫→粉渐变，其他所有卡片都是白色。渐变一多就廉价了。
4. **阴影带颜色**。阴影不是纯黑，而是偏紫的深蓝 `rgba(30, 25, 90, …)`，扩散大、透明度低，看起来像光透过来，而不是脏。
5. **颜色要有含义**。蓝 = 新的，橙 = 学习中，绿 = 已掌握，红 = 忘了。同一种颜色在全 App 里只表达一件事。

---

## 2. 色板

### 中性色

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#f5f6fb` | `#0e1016` | 页面底色 |
| `--panel` | `#ffffff` | `#161922` | 卡片 |
| `--panel-2` | `#f3f4fa` | `#1c202b` | 卡片里的次级区块（计数格、输入框） |
| `--panel-3` | `#eceef6` | `#232836` | 悬停、按下 |
| `--border` | `#e7e8f0` | `#262b38` | 分隔线、卡片描边 |
| `--text` | `#1b1f2e` | `#e9ebf3` | 正文（不用纯黑） |
| `--muted` | `#646a80` | `#9ea4b8` | 说明文字 |
| `--faint` | `#9ba1b5` | `#6b7186` | 占位、禁用 |

所有灰都略微偏蓝紫，和品牌色是一家人。

### 品牌色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--accent` | `#6d5bff` | 主按钮、选中态、链接 |
| `--accent-soft` | `#efedff`（深色：16% 透明紫） | 选中项背景、标签底色 |
| `--accent-text` | `#5444e6`（深色：`#b2a8ff`） | 浅紫底上的文字 |
| `--grad` | `#6d5bff → #8b5cf6 → #ec4899`（135°） | 全屏唯一的主视觉卡片 |

### 语义色（学习状态与评分）

| 含义 | 颜色 | 出现在 |
| --- | --- | --- |
| 新词 / 简单 | `#3b82f6` 蓝 | 计数、评分按钮、看板 |
| 学习中 / 困难 | `#f97316` / `#f59e0b` 橙 | 同上 |
| 已掌握 / 良好 | `#10b981` 绿 | 同上 |
| 重来 | `#ef4444` 红 | 同上 |

语义色和品牌紫刻意分开：紫色永远表示「可以操作」，蓝绿橙红永远表示「状态」。

### 雾气背景

```css
--bg-grad:
  radial-gradient(1200px 600px at 100% -10%, rgba(139, 92, 246, 0.08), transparent 60%),
  radial-gradient(900px 500px at -10% 110%, rgba(236, 72, 153, 0.06), transparent 60%);
/* 深色模式把透明度提到 0.12 / 0.07，否则看不出来 */
```

## 3. 形状与层次

**圆角**：大卡片 22px，普通卡片 16px，按钮和输入框 10～14px，标签和徽章用全圆角（99px）。越大的东西圆角越大，嵌套时内层比外层小一档。

**三级阴影**（全部偏紫，扩散大、透明度低）：

```css
--shadow-sm: 0 1px 2px rgba(20, 22, 50, .05), 0 1px 1px rgba(20, 22, 50, .03);   /* 按钮、小元素 */
--shadow:    0 1px 2px rgba(20, 22, 50, .04), 0 8px 24px -6px rgba(30, 25, 90, .10); /* 卡片 */
--shadow-lg: 0 2px 6px rgba(20, 22, 50, .05), 0 24px 60px -12px rgba(40, 30, 120, .22); /* 弹窗、悬停抬起 */
```

关键是第二层阴影的**负扩散**（`-6px`、`-12px`）：阴影只在卡片正下方，不会糊满四周。

**磨砂侧边栏**（桌面）：半透明白 `rgba(255,255,255,.72)` + `backdrop-filter: blur(24px) saturate(1.4)`，能隐约透出背后的雾气。

---

## 4. 字体与数字

- 用系统字体：`-apple-system, "SF Pro Text", "PingFang SC", "Segoe UI", "Microsoft YaHei"`，每个平台都显示得最清晰，也不用额外加载字体文件。
- **大数字是主角**：「今日待学」用 56px、字重 800、字距 -1.5px。数字越大，字距收得越紧，看起来才紧凑有力。
- 小号大写标签加一点字距（0.6px），正文不加。
- 数据列用等宽数字 `font-variant-numeric: tabular-nums`，对齐时不会跳。

---

## 5. 动效

- 只做**很短**的过渡：颜色 0.15s，悬停抬起 `transform 0.12s`，进度条 0.4s。
- 卡片悬停时向上 2～3px，并换成 `--shadow-lg`，像被拿起来。
- 不做循环动画，不做大面积飘动的背景（会让人分心，也会让手机发热）。

---

## 6. 手机版：液态玻璃

手机上在雾紫的基础上加了一层「玻璃」，对齐 iOS 的液态玻璃风格：

```css
--glass-bg:     rgba(255, 255, 255, .50);          /* 普通玻璃 */
--glass-bg-strong: rgba(255, 255, 255, .74);       /* 需要可读性的玻璃（弹窗、Tab 栏） */
--glass-blur:   blur(26px) saturate(190%);         /* 饱和度拉高，透出来的颜色更鲜 */
--glass-border: rgba(255, 255, 255, .75);
--glass-hl:     inset 0 1px .5px rgba(255,255,255,.95), inset 0 -1px 1px rgba(255,255,255,.35);
--glass-shadow: 0 12px 32px -12px rgba(48, 36, 140, .28), 0 2px 8px rgba(48, 36, 140, .08);
```

要点：

- **玻璃需要背后有颜色**。纯白背景上的毛玻璃什么都看不出来，所以手机版的雾气比桌面更浓。
- **上亮下暗的内描边**（`--glass-hl`）是玻璃质感的关键：顶部一条亮线像反光，底部一条弱亮线像折射。
- 底部 Tab 栏悬浮在内容上方，不贴边，四周留出安全区（`env(safe-area-inset-bottom)`）。
- 弹窗改成从底部升起的面板，符合单手操作。

## 7. 搬到其他 App 时

**照着做**

- 先定中性色（偏品牌色相的灰），再定一个品牌色，最后定语义色。
- 用 CSS 变量写所有颜色，深色模式只改变量值，不改组件样式。
- 每屏挑一个最重要的东西给渐变，其余保持白卡片。
- 阴影带上品牌色相，并用负扩散。

**避免**

- 到处都是渐变，或者每张卡片都有彩色边框。
- 品牌色同时表示「可点击」和「状态」。
- 纯黑文字（`#000`）和纯黑阴影。
- 大面积的持续动画。

**最小可用版本**：把第 2 节的中性色、品牌色和雾气背景，加上第 3 节的三级阴影和圆角复制过去，就已经有八成的「雾紫」味道了。
